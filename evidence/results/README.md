# Evidence captured during live sessions lives here.

- One CSV + log per evidence run (timestamped filename = run ID).
- `EVIDENCE-RESULTS.md` is generated by `summarize-evidence.ps1`.
- `snapshots/` holds the Grafana screenshots (trace waterfall, RED panel,
  service graph) - capture one per evidence script run.

## Per-capture README pattern

Each live session adds:

```
results/
  ingest-20260818-XXXXXX.csv   <- E1: trace IDs, span counts, verdict
  ingest-20260818-XXXXXX.log
  correlation-20260818-XXXXXX.csv
  latency-20260818-XXXXXX.csv  <- E3: per-span durations (the money table)
  resilience-20260818-XXXXXX.csv
  snapshots/
    README.md                  <- what each screenshot shows, run IDs
```
